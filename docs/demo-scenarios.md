# SmartOP Guided Demo Scenarios

## Scenario A: HR Manager Workflow
1. Login as `hr@j2k.com`
2. Navigate to `/admin/employees`
3. Add or view employee record
4. Review attendance logs at `/admin/attendance`
5. Process monthly payroll run at `/admin/payroll`

## Scenario B: Standard Employee Self-Service
1. Login as `employee@j2k.com`
2. Navigate to `/check-in`
3. Test GPS Geofence Check-in
4. Submit Leave Request at `/leave`
5. Download Payslip at `/payslip`

## Scenario C: Site Supervisor Workflow
1. Login as `supervisor@j2k.com`
2. Navigate to `/operations`
3. Review team attendance
4. Approve pending attendance / leave requests
5. Issue Work Order at `/admin/operations/work-orders`

## Scenario D: Operations Coordinator Workflow
1. Login as `coordinator@j2k.com`
2. Navigate to `/admin/operations/map` (GIS Command Center)
3. Manage Workforce Planning at `/admin/schedule`
4. Inspect industrial site boundaries at `/admin/sites`

## Scenario E: Executive Strategic Review
1. Login as `executive@j2k.com`
2. Review executive KPIs at `/admin/dashboard`
3. Analyze operational ROI at `/admin/roi`
4. Export analytics reports at `/admin/reports`

## Scenario F: System Administrator Governance
1. Login as `admin@j2k.com`
2. Manage RBAC roles & permissions at `/admin/security/roles`
3. Audit session activity at `/admin/security/sessions`
4. Review customer demo feedback at `/admin/demo-feedback`
